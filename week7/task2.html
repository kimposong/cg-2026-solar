자동 시작 설정을 고르는 중…

지원 브라우저에서는 WebGL GPU 타이머로 그리기 명령의 실행 시간을 잽니다. 미지원 기기에서는 동기화 포함 경과 시간을 표시합니다. 측정 종류가 다르면 수치를 직접 비교하지 마세요. 고부하 설정은 낮은 값부터 한 단계씩 올리세요.

자동 시작 설정은 ① 이 기기에 저장한 설정 → ② 접속 직후 공통 조건(640×360 · 8표본 · 2회 반사 · 고급 효과 켬) path tracing 을 몇 번 그려 본 시작 벤치마크 순서로 정합니다. 측정 결과는 아래 「측정 기록」에 쌓이고 보고서용 Markdown 으로 복사할 수 있습니다.
